CORREÇÃO — CONEXÃO AUTOMÁTICA DO ACESSO REMOTO

O que foi corrigido
- A URL temporária agora inclui coretuner=1 para identificar somente sessões abertas pela Central.
- O custom.js usa o mesmo fluxo do botão oficial Conectar: connectDesktop(..., 3).
- O script espera o computador/painel ficarem prontos.
- Se a sessão ficar presa em "Desconectar / Desconectado", ela é limpa e tentada novamente.
- O padrão de consentimento foi ajustado para 65 (não assistido com barra/aviso visível).
- O CoreTuner passa a servir a versão atual do script em /remote-assets/meshcentral-custom.js.

COMO APLICAR

1) Extraia este ZIP dentro da pasta principal do CoreTuner Central e substitua os arquivos.

2) Envie ao Git:
   git add .
   git commit -m "Corrige conexão automática do acesso remoto"
   git push

3) Aguarde o deploy do serviço coretuner.

4) No terminal do serviço coretuner-remote, rode:

   curl -fsSL \
     https://apps-coretuner.9ywrah.easypanel.host/remote-assets/meshcentral-custom.js \
     -o /opt/meshcentral/meshcentral/public/scripts/custom.js

   node --check /opt/meshcentral/meshcentral/public/scripts/custom.js
   wc -c /opt/meshcentral/meshcentral/public/scripts/custom.js

5) Feche as telas remotas antigas, volte para /central, pressione Ctrl + Shift + R e abra uma NOVA sessão.

- reinstalar o CoreTuner no computador;
- reinstalar o Mesh Agent;
- alterar a chave de login;
