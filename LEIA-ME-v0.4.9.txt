CORETUNER v0.4.9 — ACESSO REMOTO AUTOMÁTICO CORRIGIDO

Fluxo:
- cria ou encontra um grupo MeshCentral exclusivo para cada empresa;
- garante o usuário coretuner-integracao;
- baixa o agente correto do grupo;
- substitui um Mesh Agent antigo somente após autorização do Windows;
- aguarda o computador ficar online no MeshCentral;
- salva o ID real do dispositivo remoto;
- abre diretamente o computador selecionado.

Compatibilidade de identificadores:
- instalações antigas: 32 bytes / 64 caracteres hexadecimais;
- MeshCentral atual: 48 bytes / 96 caracteres hexadecimais.

DEPLOY
1. Use este pacote completo em uma pasta nova.
2. Faça push da branch main.
3. Aguarde o redeploy do serviço coretuner.
4. Baixe um CoreTunerSetup.exe novo pelo site.
5. Execute o Setup e escolha SIM para o acesso remoto.

Não altere o coretuner-remote nem a chave já validada.
