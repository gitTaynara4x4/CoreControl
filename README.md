# CoreControl v10.8 — Otimização visual premium

Patch somente com os arquivos alterados, para aplicar por cima da v10.7.2.

## O que mudou
- Card de Otimização redesenhado para ter mais impacto visual sem ficar infantil.
- Cabeçalho "Otimização inteligente" com status do perfil.
- Destaques visuais para Backup automático, Aplicação remota, Ajustes seguros e Restauração.
- Quatro perfis com identidade própria, ícones, foco de uso e lista de ações.
- Botões mais claros: "Ativar Conservador", "Ativar Equilibrado", etc.
- Área de rollback/restauração mais evidente e profissional.
- Dark mode e responsividade preservados.
- Cache bust atualizado para v10.8.

## Preservado
- Otimização remota Agent 0.9.0.
- Lista de aplicativos não some durante atualização automática.
- Abas/favicons/agrupamento e demais correções anteriores.

## Deploy
Substitua os arquivos mantendo a estrutura de pastas, faça Force Rebuild do CoreControl e depois Ctrl+F5 no navegador.

Não precisa reinstalar o Agent da Luiza: esta versão altera apenas o painel web.
