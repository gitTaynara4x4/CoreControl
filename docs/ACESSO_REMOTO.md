# CoreTuner Remote

A versão 0.4.7 integra o CoreTuner ao MeshCentral/MeshAgent.

- O Setup pergunta explicitamente se o usuário autoriza a instalação do acesso remoto.
- A instalação do MeshAgent solicita elevação do Windows.
- O agente remoto utilizado neste pacote está vinculado ao grupo `CoreTuner - Teste` do servidor configurado.
- O painel registra a solicitação antes de abrir a área de trabalho remota.
- Terminal e arquivos não são acionados pelo CoreTuner.

O MeshCentral e o MeshAgent são projetos de código aberto mantidos por Ylianst e distribuídos sob licença Apache-2.0.
Projeto oficial: https://github.com/Ylianst/MeshCentral
