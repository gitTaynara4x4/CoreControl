CORETUNER CENTRAL COMPLETO — v0.4.9 CORRIGIDO

Este pacote substitui a pasta antiga inteira.

O que fazer:
1. Feche o CoreTuner e o instalador no Windows.
2. Apague ou renomeie a pasta antiga do projeto.
3. Extraia este ZIP em uma pasta nova.
4. Não crie um arquivo .env com chaves antigas. No EasyPanel, as variáveis continuam salvas no próprio serviço.
5. Abra o PowerShell dentro da nova pasta.
6. Execute: git status
7. Execute: git push origin main
8. Aguarde o deploy do serviço coretuner.
9. Apague o CoreTunerSetup.exe antigo do computador.
10. Baixe o instalador novamente pelo site e escolha SIM para o acesso remoto.

IMPORTANTE
- Não altere o serviço coretuner-remote, o usuário user-mesh-adm ou a chave que já foi validada.
- O acesso remoto agora aceita identificadores MeshCentral antigos de 32 bytes e atuais de 48 bytes.
- O download do Mesh Agent usa o identificador Base64 original do grupo; o hexadecimal fica apenas para validação local.
- O pacote não contém .env real, banco de dados de produção ou ambiente virtual .venv.
- Os executáveis oficiais estão em app/downloads.
