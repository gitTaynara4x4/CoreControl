CORETUNER CENTRAL 0.4.3 — VALIDAÇÃO REALIZADA

- Projeto reconstruído sem a pasta duplicada central, sem .venv, sem caches e sem bancos usados em testes.
- Existe apenas uma cópia oficial de cada executável em app/downloads.
- CoreTuner.exe, CoreTunerAgent.exe e CoreTunerSetup.exe compilados como aplicativos gráficos Windows x64.
- go test e go vet aprovados nos três módulos Go.
- 5 testes automatizados do backend aprovados.
- Backend iniciado na porta 8002; /health respondeu 200 com a versão 0.4.3 e o site respondeu 200.
- JavaScript do site e do painel passou na verificação sintática.
- Nenhum dos três executáveis compilados contém referência a powershell.exe.
- Agent e aplicativo completo coletam informações usando APIs nativas do Windows.
- Setup encerra versões antigas do CoreTunerAgent antes de instalar a nova.
- Nenhuma otimização do Windows é aplicada nesta versão; os perfis permanecem apenas para seleção e revisão.

LIMITAÇÃO DE VALIDAÇÃO
- Os executáveis foram compilados para Windows, mas este ambiente não executa a interface gráfica do Windows. A abertura visual e o monitoramento contínuo precisam ser confirmados no seu computador antes de uso em cliente.
- Temperatura pode aparecer como indisponível nesta versão, porque a coleta externa via PowerShell foi removida e sensores variam conforme o hardware.
